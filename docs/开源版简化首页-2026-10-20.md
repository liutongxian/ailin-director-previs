# v0.2.3 · 双入口首页

本版恢复独立开源核心的公开发布，许可证保持 Apache-2.0。

## 本次调整

- 每次启动先显示首页，只提供“导演包一键生成白模预演”和“手动搭建白模预演”两个入口。
- 进入工作区后再提供项目打开／保存、搭景、拍摄和白模导出；返回首页并切换入口不会替换当前项目。
- 导演包页移除 TXT／MD 本地识别与单独 Previs IR 导入入口，保留导演包提示词、包校验、镜头审阅与生成预演。
- 历史项目和底层格式继续兼容；Three.js／Blender 本机导出保持原流程。
- 商业版源码、商业授权、商业安装程序及现有交付 ZIP 不作修改，也不加入公开仓库。

## 验证

- TypeScript 检查、ESLint、1,013 项单元测试通过。
- 源码运行：从导演包导入到 Blender／FFmpeg 的真实 MP4 导出通过；手动搭景工作区到 Blender MP4 导出通过。
- 检查首页只有两个功能按钮；两个入口均可进入对应工作区；导入后返回首页、切换工作区，镜头卡仍能恢复。
- Windows 打包版：实际打开打包后的程序，检查双入口首页，并完成导演包到 Blender MP4 的路径。
- 首页和导演包截图来自本版程序。Blender 5.2.0、FFmpeg 需另行安装；此 EXE 不捆绑二者。

发布附件提供 Windows x64 免安装 EXE、SHA-256 校验表及通用入门导演包。源码可从本版标签获取。
