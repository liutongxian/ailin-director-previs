# 从外部 Agent 导演包到白模视频

这份指南面向首次使用艾琳导演台开源核心的人。目标是从一份分镜出发，实际得到可播放的 MP4，而不是只看到镜头卡或概念图。

## 0. 准备软件

- Windows 10/11 x64。下载发布页的免安装 EXE；或安装 Node.js 22.12+、Git 后按 README 的命令从源码运行。
- 安装 Blender（本项目已用 5.2.0 实测）与 FFmpeg，并确认 `blender --version`、`ffmpeg -version` 能在启动导演台的 PowerShell 中运行。若不在 `PATH`，设置 `AILIN_BLENDER`、`BLOCKOUT_FFMPEG` 两个绝对路径环境变量。
- 预留项目输出空间。项目文件、导入素材和视频只写在你选择的本地项目目录；EXE 本身不内置 Blender、FFmpeg 或云模型。

先用仓库内的 [`examples/双人调度.ailin.json`](../examples/双人调度.ailin.json) 跑通一遍，再处理自己的剧本，最容易区分软件配置问题与 Agent 包内容问题。

## 1. 给外部 Agent 的提示词

打开“导演包”页面，点击“复制导演包完整提示词”。复制内容已经包含格式规则、JSON Schema 和完整示例。将它粘贴给你使用的外部 Agent，再追加自己的剧本／分镜、场景尺寸资料及有权使用的参考素材。可以补一句：

> 请严格根据上述艾琳导演包规范，把下面的分镜整理为可导入导演台的文件。剧情事实不得自行补写；不确定的尺度、走位和机位请标为 `agent-proposal`、降低 `confidence` 并列入 `unresolved`。请给每个镜头写清首、中、尾画面检查点。

只有带图片或模型时才要求 `.ailinpack`：它是 ZIP，根目录为 `director.ailin.json`，图片放 `assets/`、模型放 `models/`；随包素材必须在 `assetBindings` 列出，路径为包内相对路径。纯文本包交付 UTF-8 编码的 `.ailin.json`。若 Agent 只能回复文本，要求它只输出一个 JSON 对象（不要 Markdown 围栏），由你保存为该文件。不要让 Agent 在包内放 API Key、密码、绝对路径、白模视频或无授权素材。

外部 Agent 只是把文本与参考资料整理成调度方案；人物身份、剧情事实、空间尺度、可信度及镜头意图都需你审阅。首／中／尾文字是检查目标，不是已渲染画面。

## 2. 导入与审阅

启动后默认进入“导演包”。点击“导入艾琳导演包…”，选择 `.ailinpack`、`.ailin` 或 `.json`。界面会校验引用 ID、坐标、时长、路径和包结构；错误会显示在提示中，回到 Agent 修包后重新导入。

导入成功会显示镜头数、原始分镜、每张镜头卡的时长、画幅、实体、机位点与首／中／尾摘要。重点确认：

1. 镜头数量、顺序、人物和动作是否与原剧本一致。
2. 开始／中间／结束的站位是否符合导演意图；`unresolved` 是否有需要你决定的空间假设。
3. `generationPrompt` 仅供后续生视频模型参考，不改变白模的实际站位和运动。

不使用外部 Agent 时，可导入 `Previs IR`，或导入 TXT／MD 后点击“本地识别镜头卡”。本地识别是规则方式，复杂剧情建议用导演包并人工复核。

## 3. 一键生成可编辑预演

在镜头卡下点击“一键生成全部可编辑 3D 预演”。如果当前打开的是有内容的示例项目，程序会询问是否替换当前预演场景；确认后会保留项目参考素材，并进入“搭景”。这一步把所有镜头卡转为本地可编辑场景，不是直接渲染最终视频。

在“搭景”查看实体的空间位置、人物路径和场景构件；在“拍摄”播放镜头，检查摄影机运动、时间点和画幅。需要修改时直接在这两个页面调整。每个镜头的白模必须以你最后确认的可编辑场景为准，不能把 Agent 文本当作已批准结果。

## 4. 渲染白模 MP4

打开“白模交付”，从场景与镜头下拉框选择要生成的镜头：

- “快速白模 · Three.js”：通过程序内 3D 视口渲染，需本机 FFmpeg 编码，适合快速预览。
- “高级白模 · Blender”：真实启动本机 Blender 渲染，再调用本机 FFmpeg；同时保存可编辑 `.blend`、首中尾检查图和 H.264 MP4。第一次生成可先用示例镜头确认环境，再处理长镜头。

点击对应的“生成当前…白模”，等待状态变成“生成完成”。视频卡片可直接播放，点击“打开输出位置”查看文件。Blender 输出路径在当前项目目录下的 `generated/blender/<镜头ID>-<任务ID>/`；每次运行会建立新任务目录，不覆盖旧视频。按镜头逐个生成、检查，并点击“设为最终交付参考”。给生视频模型时附上 MP4、对应分镜和角色／场景参考；白模只负责运动与空间，不负责最终画质和声音。

## 5. 验收与排错

验收标准：镜头卡内容正确；“搭景／拍摄”能看到可编辑镜头；视频卡片可播放；输出目录有非空 MP4。Blender 高级方式还应有 `.blend` 及 `-start.png`、`-middle.png`、`-end.png` 检查图。开发者可运行 `npm run smoke`，它会自动导入示例导演包并真实渲染测试 MP4。

| 现象 | 检查 |
| --- | --- |
| 导入失败 | 确认 JSON 无 Markdown 围栏；`.ailinpack` 根目录有 `director.ailin.json`，素材路径与 `assetBindings` 一致；查看具体校验错误 |
| 导入后看不到人物或机位 | 检查镜头卡是否生成、是否点击“一键生成”、是否选中正确镜头；核对 `stagePlans.shotId` 与 Previs IR 的镜头 ID |
| 找不到 Blender | 安装 Blender，把其目录加入 `PATH` 或设置 `AILIN_BLENDER` 为 `blender.exe` 完整路径，再重启导演台 |
| 找不到 FFmpeg | 安装 FFmpeg，把 `ffmpeg.exe` 加入 `PATH` 或设置 `BLOCKOUT_FFMPEG` 为完整路径，再重启导演台 |
| 渲染失败 | 查看白模任务错误信息及输出目录日志；先用示例包验证环境，再检查自定义包的时长、素材及坐标 |
| EXE 被 Windows 提醒 | 此开源版尚未代码签名。仅从项目发布页下载并核对 SHA-256；不能确认来源时不要运行 |

发现问题时请提供：导演台版本、复现步骤、脱敏后的导演包、错误信息、Blender／FFmpeg 版本。不要提交私有剧本、素材或密钥。
