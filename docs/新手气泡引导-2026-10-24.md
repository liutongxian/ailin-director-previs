# 0.2.4 新手气泡引导

需求：在 Windows 开源版界面增加气泡新手引导，覆盖跑通示例、制作自己的导演包、生成白模视频及手动操作。

## 入口与四条路线

首次打开在右上角显示引导菜单；顶栏“新手引导”始终可重新进入。普通操作仍走原来的双入口首页，引导可关闭、切换路线、跳过某一步并继续上次进度。

- 示例：独立练习项目 → 内置双人调度导演包 → 首中尾审阅 → 可编辑3D生成 → 播放 → 选择输出引擎 → 真实MP4 → 检查/打开输出 → 保存。
- 自己的导演包：复制完整提示词/Schema/示例 → 连同剧本发给外部AI → 保存正确的导演包文件 → 导入校验 → 审阅、生成和编辑 → 白模交付。软件不自动调用外部模型。
- 白模：选场景和镜头 → 选快速或高级引擎 → 等到生成真正成功 → 检查/取出MP4 → 保存。
- 手动：新建项目 → 选资产并在地面放置 → 修改属性 → 人物走位关键点 → MS自动构图 → 摄影机关键点 → 时间轴播放 → 保存 → 白模交付。

## 交互与数据保护

气泡使用真实控件位置定位，高亮不拦截底层鼠标操作。窗口尺寸、滚动、页面和内容变化会触发重新定位；步骤开始时会将控件滚到可见位置，长导演包也能找到末尾生成按钮；找不到控件时提供返回该页面入口。关键步骤监听成功事件或实际编辑状态，不把失败的导入/渲染认定为完成。

进度只存在本机localStorage，损坏、旧值或存储不可用时可安全回退。关闭后不反复弹出，重开时可继续原路线；完成路线只标记“已浏览”，不代表已人工验收最终画面。Esc优先退出资产/关键点放置，再关闭引导。

开始示例需明确点击，并检查未保存修改；取消切换时原工程不变。每次示例使用唯一目录，避免同一秒重复打开覆盖旧练习。仅在工作区真正变化时切换模式，保留用户刚选中的待放置资产。白模生成期间不能从引导跳换工程；生成失败仍停在该步，并能修复后重试或明确跳过。

## 运行条件与版本

开源EXE不捆绑Blender或FFmpeg。快速白模需要FFmpeg；高级白模还需Blender。入门导演包已编入程序，无需联网或另找示例文件。若编码器未启动/提前退出，会提示检查FFmpeg配置，而不是只展示内部任务编号。

Windows启动器可选用`BLOCKOUT_USER_DATA_DIR`指定独立配置目录、`BLOCKOUT_PROJECTS_DIR`指定示例/新建项目的默认位置；不设置时沿用原有路径。此机制便于新版本演示与仍在运行的旧程序隔离，不迁移或覆盖旧项目。`BLOCKOUT_SMOKE_DIR`仅用于隔离测试。

本版在独立开源仓库构建；既有商业版、商业发布包、授权数据和0.2.3文件不改动。Windows便携程序、源码ZIP、入门导演包及SHA-256清单通过 [v0.2.4发布页](https://github.com/liutongxian/ailin-director-previs/releases/tag/v0.2.4) 交付；源码标签为`v0.2.4`。

## 验证

- 单元测试：进度损坏/旧值/原型属性、存储不可用及窗口边界定位。
- 桌面流程：内置示例真实生成并保存H.264 MP4，关闭/重载/续看，错误导演包不推进，取消示例切换保留未保存内容，实际人物放置/走位/构图/机位/保存，缺少编码器不误报完成且可重试。
- 保留原导演包到Blender MP4、手动到Blender MP4回归；同时检查便携包内的气泡和内置示例。
- 类型检查、lint、1017项单元测试为本轮检查范围；实际Windows打包和桌面验收记录随交付保存。

限制：引导不代替导演判断，不自动安装依赖、生成云视频或把白模当成最终成片。当前主体引导为中文，原有界面语言切换仍可使用。

最终检查范围：33个测试文件/1017单元测试；8条源码桌面流程（含6条新手专项及2条原Blender回归）；打包程序重复运行6条新手专项与1条Blender流程。均使用隔离项目和本地工具，不调用云端模型。
