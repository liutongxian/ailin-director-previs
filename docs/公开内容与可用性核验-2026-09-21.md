# 公开内容与可用性核验（2026-09-21）

本记录对应 v0.2.1 开源核心。核验范围是公开仓库的当前文件与全部公开提交、Windows 发布附件、示例媒体及从源码到白模视频的主要运行路径；它不是对任何第三方依赖或未来用户导入内容的无限期保证。

## 公开边界

- 仓库保留上游 Blockout 的 `LICENSE`、`NOTICE` 和修改说明；商业授权、管理台、云端生视频集成、模型密钥、私有项目和私人素材均不在本开源核心的功能边界内。
- 仓库跟踪文件、公开提交历史、发布附件名称及打包程序内文件清单已逐项检查。未发现真实 API 密钥、访问令牌、邮箱、私人绝对路径或私有项目文件；代码中有用于演示／测试的假路径、通用场景词和本机随机 Token 的实现说明。
- 展示视频的画面是三组通用白模案例；视频容器元数据未发现姓名、地理位置或本机路径。展示 PNG 未发现 PNG 文本或 EXIF 信息。示例导演包是通用“双人调度”镜头。
- 文档和帮助页只引导开源版实际提供的流程：外部 Agent 导演包、审阅、可编辑预演、本机 Three.js／Blender 白模；本开源核心不承诺云端模型提交或自动拼接长视频。

## 可复现的功能核验

在干净的 `npm ci` 依赖安装后运行：

```powershell
npm run typecheck
npm run lint
npm test
npm run smoke
npm run package:win
npx playwright test tests/e2e/packaged.spec.ts
```

其中 `npm test` 共 1,013 项单测通过；`npm run smoke` 在 Electron 中完成两条真实 Blender／FFmpeg 渲染链路，其中一条从导入随仓库的导演包开始。打包版测试再次从 EXE 运行相同的导演包到 MP4 路径。运行这些视频测试需要本机安装 Blender、FFmpeg，并将其放入 `PATH` 或设置文档中的环境变量。

## 仍须由发布者和使用者确认

- 开源仓库的技术扫描不能证明每一张自制图标、示例画面及用户后续导入的素材都拥有对外再授权权利；发布者应保留原创／授权来源记录，使用者应只导入有权使用的内容。
- EXE 暂未提供可信代码签名。只从项目发布页获取，核对该版本发布说明中的 SHA-256；不要把陌生来源的同名 EXE 当成此构建。
- 本机 MCP 控制服务使用随机 Token 且仅监听环回地址；不要分享配置目录中的发现文件，也不要把自己的剧本、素材或密钥上传到公开 Issue。
