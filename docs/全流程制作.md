# 全流程制作 · 0.3.0-alpha.1

这是开发版功能，入口在首页的“开始全流程制作”。已有白模编辑器、导演包导入和新手引导继续保留。

## 六步完成一个项目

1. **写剧本**：输入或导入 TXT / Markdown，留存剧本版本。
2. **拆分镜**：在“拆镜模型设置”填写自己的兼容 Chat Completions 接口地址、模型名称和密钥，点击“智能拆镜并整理素材”。结果包括可编辑镜头、人物 / 场景 / 道具清单、图片提示词及镜头关联。检查剧情、人物身份与动作，再继续制作。也可手动拆分，或从高级入口导入导演包。
3. **做素材**：逐项修改图片提示词，导入已有图片或调用生图接口。生成图片进入项目素材库，并关联需要该资产的镜头。重做会保留旧版本；已有选定图片时，需点击“使用这张并关联”采用新版。图片、视频、音频都可作为项目素材导入。
4. **看预演**：用 Three.js 或 Blender 检查构图、走位与机位。白模视频可加入当前镜头的生成参考。
5. **生成视频**：按镜头选择服务商、模型、提示词及参考素材，指定人物、场景、首尾帧、动作或机位等用途。软件根据模型能力检查输入。提交后查询进度、下载结果并选择采用版本。请求状态不明确时先核对原任务，避免重复付费。
6. **导出成片**：将已采用的本地视频按镜头顺序合并，可裁去首尾、填写逐镜字幕并选择配乐。输出 MP4 与独立 SRT 字幕文件；字幕不会自动烧录进视频。导出依赖 FFmpeg / FFprobe。

所有项目、导入素材、任务回执和输出保存在本机。首次启动创建空白项目；可从“项目与说明”打开已有项目或创建自己的项目。

## 模型入口

| 环节 | 当前入口 | 配置方式 |
| --- | --- | --- |
| 剧本拆镜 | DeepSeek 等兼容 Chat Completions 的文字模型 | 填写服务地址、模型名称、自己的 API Key |
| 云端图片 | 火山方舟 Seedream、MiniMax Image-01 | 在素材制作处选择模型并填写 API Key |
| 本地图片 | Unsloth Studio 中的 Qwen-Image 2.1 | 填写本机或局域网地址、登录密码，先检查连接 |
| 云端视频 | MiniMax H3、火山方舟 Seedance、BytePlus LAS Seedance | 按镜头选择预设服务与模型，填写自己的 API Key |

模型名称、可用分辨率、参考数量及账户权限以服务商实际接口为准。预设不代表账户已经开通，也不包含额度。任意云端供应商尚不能直接接入；增加不同协议的供应商需要补充适配器。

本地 Qwen 需要事先安装 Unsloth Studio、准备模型，并在 Studio 内加载 Qwen-Image 2.1。导演台不下载模型、不自动加载模型，也不修改显存或系统内存设置。默认地址为 `http://127.0.0.1:8888`；其他电脑可填写可达的局域网地址。请在“检查本地连接”确认服务与模型已就绪后生成。

## 密钥与项目

- 本仓库不包含 API Key、登录密码、`.env`、个人项目或本机配置。
- 界面输入的生图、生视频密钥及 Unsloth 密码仅在本次运行内使用，不写入项目或任务回执。拆镜密钥可读取本机已有的系统加密存储；当前界面输入的密钥不自动保存。
- 云端接口也可读取启动环境中的 `ARK_API_KEY`、`MINIMAX_API_KEY`、`BYTEPLUS_LAS_API_KEY`；本地服务可读取 `LOCAL_QWEN_PASSWORD`。程序不自动读取任意 `.env` 或机器上的密码文件。
- 服务地址与模型设置会保存；不要把密钥或密码放进地址、提示词或项目名称。项目内容及选中的参考素材会在点击生成时发送至所选服务。
- 不要把个人项目、配置、测试输出和凭据目录加入 Git。`.gitignore` 已排除常见凭据文件、运行目录和 `.blockout` 项目目录。

单元测试覆盖请求构建、参数验证、错误脱敏、任务回执、素材关联和项目保存。Electron 测试用虚构内容与模拟云端响应验证拆镜 → 资产 → 镜头关联、项目迁移重开，以及真实 FFmpeg 合并与字幕时间。
