# 双人调度 · 公开入门示例

这是虚构的通用软件示例，不包含私人素材、API Key、云端生成回执或本机配置。

## 直接体验

1. 下载并解压 `ailin-quickstart.zip`。
2. 启动导演台，选择“开始全流程制作”。
3. 点击顶部“项目与说明” → “打开项目”，选择解压后的 `Quickstart.blockout` 文件夹（不要选择里面的 JSON 文件）。
4. 依次查看“写剧本”“拆分镜”“做素材”“看预演”。项目已预置一段剧本、一个可编辑镜头、三项资产需求与图片提示词，无需调用模型即可查看。
5. 在“做素材”导入你自己的图片并关联；在“看预演”调整走位与机位。

预演画面可直接查看；导出白模 MP4 需要 FFmpeg，Blender 模式还需要 Blender。图片/视频云端生成需要自己的账户及额度；本示例没有预生成云端成片。

Source users: open this `quickstart` folder through Project & Help → Open Project. The app UI is currently primarily Chinese. The ZIP contains the same project under `Quickstart.blockout`.

This fictional sample includes one editable shot, two characters, one location and three editable image prompts. No API key is needed to inspect it. Rendering requires FFmpeg; cloud generation requires your own provider account.
